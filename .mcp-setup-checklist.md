# MCP Setup Checklist

Quick checklist for activating MCP servers. Check off items as you complete them.

## Phase 1: Immediate Setup (5 minutes)

### GitHub MCP Server (Required for Development)
- [ ] Visit https://github.com/settings/tokens
- [ ] Click "Generate new token (classic)"
- [ ] Select scopes: `repo`, `workflow`, `read:org`
- [ ] Copy token
- [ ] Add to `.env` file: `GITHUB_TOKEN=your_token`
- [ ] Test: Ask Claude "List my GitHub repositories"

## Phase 2: Production Setup (Optional, 15 minutes)

### Sentry MCP Server (Recommended for Production)
- [ ] Create account at https://sentry.io
- [ ] Create a new project
- [ ] Go to Settings → API → Auth Tokens
- [ ] Create new auth token
- [ ] Add to `.env`:
  ```
  SENTRY_AUTH_TOKEN=your_token
  SENTRY_ORG=your_org_name
  SENTRY_PROJECT=your_project_name
  ```
- [ ] Test: Ask Claude "Show me recent errors in Sentry"

## Phase 3: Team Collaboration (Optional, 20 minutes)

### Slack MCP Server
- [ ] Visit https://api.slack.com/apps
- [ ] Click "Create New App" → "From scratch"
- [ ] Add bot token scopes:
  - [ ] `channels:history`
  - [ ] `channels:read`
  - [ ] `chat:write`
  - [ ] `files:read`
  - [ ] `search:read`
  - [ ] `users:read`
- [ ] Install app to workspace
- [ ] Copy Bot User OAuth Token (xoxb-...)
- [ ] Copy App-Level Token (xapp-...)
- [ ] Add to `.env`:
  ```
  SLACK_BOT_TOKEN=xoxb-...
  SLACK_APP_TOKEN=xapp-...
  ```
- [ ] Test: Ask Claude "Search Slack for messages about campaigns"

### Figma MCP Server
- [ ] Visit https://www.figma.com/developers/api#access-tokens
- [ ] Generate Personal Access Token
- [ ] Add to `.env`: `FIGMA_TOKEN=your_token`
- [ ] Test: Ask Claude "Get color palette from Figma file X"

## Phase 4: Activation (1 minute)

### Enable Servers
- [ ] Restart Claude Code
- [ ] When prompted, approve MCP servers
- [ ] OR: Add to `.claude/settings.local.json`: `"enableAllProjectMcpServers": true`

### Verify Installation
- [ ] Type `/mcp` in Claude Code
- [ ] Verify servers show as "connected"
- [ ] Test GitHub: "Show my repositories"
- [ ] Test Memory: "Remember that our audience is Gen Z"
- [ ] Test Puppeteer: "Take screenshot of google.com"

## No Setup Required

These servers work out of the box:
- [x] **Puppeteer** - Browser automation (no credentials needed)
- [x] **Memory** - Knowledge graph (no credentials needed)

## Environment Variables Summary

Copy this to your `.env` file and fill in your tokens:

```bash
# === MCP Servers Configuration ===

# GitHub (Required)
GITHUB_TOKEN=

# Sentry (Optional - Production monitoring)
# SENTRY_AUTH_TOKEN=
# SENTRY_ORG=
# SENTRY_PROJECT=

# Slack (Optional - Team collaboration)
# SLACK_BOT_TOKEN=
# SLACK_APP_TOKEN=

# Figma (Optional - Design integration)
# FIGMA_TOKEN=
```

## Quick Tests

After setup, try these commands:

```
GitHub:     "Show me open pull requests"
Puppeteer:  "Screenshot https://google.com"
Memory:     "Remember target audience is Gen Z"
Sentry:     "Show recent errors" (if configured)
Slack:      "Search Slack for X" (if configured)
Figma:      "Get design specs" (if configured)
```

## Troubleshooting

**Server won't connect:**
- [ ] Check token is in `.env`
- [ ] Verify token has correct permissions
- [ ] Restart Claude Code

**Permission denied:**
- [ ] Regenerate token with correct scopes
- [ ] Check workspace/org access

**Server not listed:**
- [ ] Verify `.mcp.json` exists
- [ ] Restart Claude Code
- [ ] Check for typos in configuration
