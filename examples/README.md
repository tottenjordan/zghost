# Examples

## NovaStorm Demo

See how skills evolve through self-reflection:

```bash
cd /usr/local/google/home/jwortz/zghost
uv run python examples/novastorm_demo.py
```

This demo shows:
- 3 generations of skill evolution
- Score progression from 6.5 → 7.8 → 8.9
- Different evolution strategies (mutate, crossover, explore)
- Memory Bank integration (if configured)

No Memory Bank required — the demo will work with or without it.
